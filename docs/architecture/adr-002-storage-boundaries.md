# ADR-002：数据库与文件存储边界

- 状态：已接受
- 日期：2026-08-05

## PostgreSQL/PostGIS 保存

- 用户和认证信息
- 分析任务、状态和进度
- 研究区、缓冲区几何
- 指标元数据和权重配置
- 分析参数与结果摘要
- 文件相对路径和生命周期
- 操作日志

## 文件系统或对象存储保存

- 12 项原始 GeoTIFF
- 裁剪后的指标栅格
- 综合风险 GeoTIFF
- 地图预览图
- Shapefile、CSV、ZIP、PDF 等导出成果

## Redis 保存

- Celery 消息
- 短期任务状态
- 可失效缓存

Redis 中禁止传输大型 GeoJSON、GeoTIFF 二进制或完整分析结果。
