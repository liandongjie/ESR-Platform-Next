# ADR-001：坐标系边界

- 状态：已接受
- 日期：2026-08-05

## 决策

1. 后端 API、PostGIS、GeoJSON、研究区和栅格分析统一使用 WGS84 / EPSG:4326。
2. 高德地图展示使用 GCJ-02。
3. WGS84 与 GCJ-02 转换只在前端地图适配层发生。
4. 高德地图绘制结果提交给后端前必须转换回 WGS84。
5. GCJ-02 几何禁止直接用于裁剪 WGS84 栅格。
6. 缓冲区按米计算时必须先投影到合适的米制坐标系，不能直接对经纬度执行度单位缓冲。

## 原因

地图展示坐标与空间分析坐标混用会导致研究区和栅格发生位置偏移。统一内部坐标系可以保证数据库、空间计算和文件成果的一致性。

## 后续实现

- `frontend/src/composables`：封装高德地图和坐标转换。
- `backend/app/gis`：封装几何校验、投影选择和米制缓冲。
- 通过固定控制点和回转换误差测试验证转换实现。
