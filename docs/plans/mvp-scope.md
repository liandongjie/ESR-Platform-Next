# MVP 范围

## 第一条纵向链路

1. 登录；开发环境可开放注册，Production 默认关闭并由 CLI 创建演示账号
2. 绘制研究区或选择预置风险点
3. 设置缓冲区
4. 执行 POI 分析并导出 CSV
5. 选择 12 项指标并配置权重
6. 创建异步风险分析任务
7. 查看任务进度
8. 查看风险地图、统计表和指标贡献度
9. 下载 POI CSV、风险 GeoTIFF 和结果 JSON；地图默认读取受保护 PNG preview
10. 查看本人历史任务

## 工程约束

- 结果默认保留 24 小时。
- 缓冲区默认 1000 米，暂定允许 100～5000 米。
- 分析面积暂定不超过 50 平方公里。
- 任务按用户隔离；幂等、限流和每用户活动任务数在入队前执行。
- 50 个用户可以提交和查看本人任务；GIS 计算通过 2 个 Worker 并发槽受控排队。

50 用户边界已在本机隔离 RC 使用真实栅格验证，线上容量仍需在火山引擎复测。
