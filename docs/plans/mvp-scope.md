# MVP 范围

## 第一条纵向链路

1. 注册或登录
2. 绘制研究区或选择预置风险点
3. 设置缓冲区
4. 执行 POI 分析并导出 CSV
5. 选择 12 项指标并配置权重
6. 创建异步风险分析任务
7. 查看任务进度
8. 查看风险地图、统计表和指标贡献度
9. 下载 CSV、GeoJSON、Shapefile、GeoTIFF 和 ZIP
10. 查看本人历史任务

## 工程约束

- 结果默认保留 24 小时。
- 缓冲区默认 1000 米，暂定允许 100～5000 米。
- 分析面积暂定不超过 50 平方公里。
- 50 个用户可以提交和查看任务；重计算任务通过 1～2 个 Worker 并发槽受控排队。

上述数值必须经过真实栅格基准测试后再调整。
